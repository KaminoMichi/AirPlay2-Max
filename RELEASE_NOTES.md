# 0.1.0-rc.1

Первая публичная упаковка YA AirPlay 2. Основа — испытанная владельцем связка SF1 + VP2: звук, громкость и команды работали нормально на YNDX-00052 с прошивкой 5000000921. Новая упаковка ещё не получила отдельного подтверждения на устройстве, поэтому релиз помечен prerelease.

В пакете одна текущая версия: receiver, NQPTP, управление процессами, NSD и Volume Bridge. Добавлены установка одной командой с подтверждением, проверка совместимости/SHA, резервная копия при обновлении, удаление и откат. Голосовой мост «Алиса, пауза» включается отдельно.

Автозапуск подготовлен для существующего `/data/adb/service.d`. На исходной конфигурации Hybrid Root 1.2.4 такой hook не найден; автоматический запуск для неё пока не заявлен. После ручного запуска голосовой мост может ожидать iPhone без активного воспроизведения.

Перед стабильным релизом нужно проверить установку/остановку/удаление на Android, повторные подключения, длительное воспроизведение, Mac и перезагрузку. Next/Previous и голосовые Play/Next/Previous не заявляются проверенными. Сетевые настройки и системные разделы установщик не меняет.

Файлы релиза: установочный архив, исходники проекта, соответствующие исходники зависимостей, комплект перелинковки и SHA256SUMS. Для пользователей достаточно установочного архива; остальные материалы обеспечивают проверку и пересборку.
