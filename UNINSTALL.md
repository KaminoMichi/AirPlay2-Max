# Удаление и откат

Эти действия относятся только к публичной установке `/data/local/tmp/ya-airplay`. Старые экспериментальные папки и заводские компоненты не затрагиваются.

## Остановить без удаления

```sh
python3 tools/airplayctl.py stop --root rootd --hybrid-root-version 1.2.4
```

Голосовой мост останавливается раньше receiver; supervisor завершает и дожидается только собственных дочерних процессов. Если чистая остановка не подтверждена, дальнейшее удаление прекращается. Команд `kill` по сохранённым PID нет.

## Удалить установленную версию

```sh
python3 uninstall.py --root rootd --hybrid-root-version 1.2.4
```

После подтверждения останавливается наш AirPlay, удаляется только принадлежащий проекту boot hook, а рабочая папка сохраняется как `/data/local/tmp/ya-airplay.failed`. Это обратимое удаление: конфигурация и журналы остаются для владельца. Существующая папка `ya-airplay.failed` не перезаписывается.

NSD APK удаляется только если его установил именно этот установщик и текущий SHA всё ещё совпадает. APK, который существовал раньше, сохраняется. Другой пакет/подпись автоматически не удаляется. Удаление самой сохранённой папки — отдельное осознанное действие владельца, автоматического рекурсивного стирания нет.

## Откат после обновления

```sh
python3 tools/airplayctl.py rollback --root rootd --hybrid-root-version 1.2.4
```

Нужна собственная `ya-airplay.previous`. Команда останавливает текущую версию, сохраняет её в `ya-airplay.failed`, возвращает предыдущую папку на рабочее место. После проверки можно запустить восстановленную версию обычной командой `start`; автоматического запуска при откате нет.

При ошибке или неизвестном владении операция прекращается. Не удаляйте служебные файлы наугад и не повторяйте установку вслепую. Сохраните текст ошибки; rootd adapter укажет каталог результата. Системные разделы, IoSDK, root, сеть и firmware не изменяются.
