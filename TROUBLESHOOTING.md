# Проблемы и диагностика

| Симптом | Что проверить |
|---|---|
| `adb` не найден | Установите Android Platform Tools на компьютер, проверьте `adb version`. |
| `unauthorized` / несколько устройств | Проверьте `adb devices`; используйте обычное подтверждение доступа и `--serial` для нужной станции. |
| Несовместимая модель/прошивка | Сверьте корпус YNDX-00052 и прошивку 5000000921. Обхода проверки нет. |
| Нет root / rootd отказал | Нужен уже установленный root указанного типа. Для rootd поддержан явно подтверждённый Hybrid Root 1.2.4. Установщик root не добывает. |
| AirPlay не виден | Проверьте `status`, нахождение iPhone и станции в одной сети, успешную регистрацию NSD. Между VLAN может требоваться настройка маршрутизации/mDNS вне этого проекта. |
| Соединение есть, звука нет | Проверьте тихое воспроизведение на iPhone, mute и системную громкость, статус receiver/NQPTP. Один живой RTSP-сеанс не доказывает звук. |
| Ошибка подписи APK | Автоматической переустановки с удалением нет. Нужны проверка владельцем прежнего APK, сохранённая копия и отдельное решение. |
| После перезагрузки не стартует | Для Hybrid Root автозапуск пока не подтверждён; выполните `start`. Параметр `--autostart required` требует уже работающего `/data/adb/service.d`. |
| Пауза не работает | Нужны активная AirPlay-сессия и `--voice on`. Проверьте действие на iPhone; ACK не равен исполнению. После перезапуска штатного SDK мост завершится безопасно. |
| Пауза при другой фразе | Это возможное ограничение маршрута SDK. Остановите AirPlay штатно; не пытайтесь менять Quasar/IoSDK. Не считаете это подтверждением распознанного намерения. |
| Ошибка после непредвиденного завершения | Состояние той же загрузки не сбрасывается автоматически. Сохраните ошибку и журналы; не удаляйте shm/socket/PID наугад. |
| Нехватка места / неизвестный файл в логах | Установка/очистка останавливаются. Не запускайте общий `rm -rf`; сохраните собственные журналы отдельно. |

Начните с `python3 tools/airplayctl.py check`, затем `status` с выбранным root-методом. Отчёт для issue должен содержать версию, модель, номер прошивки, текст ошибки и действия воспроизведения. Не публикуйте приватные ключи, токены, MAC, серийный номер, device ID, речь, аудио или полные системные журналы. Отправка диагностических архивов автоматически не выполняется.
