# YA AirPlay 2

AirPlay 2 для Яндекс.Станции Макс с Zigbee. Звук выводится через штатную аудиосистему Android; установка размещается в `/data`.

**Версия 0.1.0-rc.1 — кандидат в релиз.** Основа — последняя испытанная владельцем связка SF1 + VP2: воспроизведение, громкость и команды работали нормально. Новый установочный пакет и поведение после перезагрузки ещё требуют испытания на станции. Это не стабильный релиз для всех моделей.

## Совместимость

| Параметр | Поддерживаемая конфигурация |
|---|---|
| Устройство | Макс с Zigbee, **YNDX-00052** — сверить маркировку корпуса |
| Платформа | `yandexstation_2` |
| Прошивка | **5000000921**, с точной проверкой fingerprint |
| Система | Android 9 / API 28, ARM64 |
| Доступ | Уже работающие ADB и root; для Hybrid Root — версия 1.2.4 |
| SELinux | Испытана конфигурация Permissive; установщик режим не меняет |

Совпадение платформы само по себе не доказывает совместимость другой модели. На других прошивках установка останавливается. Root, прошивка и изменение механизма восстановления в этот проект не входят.

## Возможности

- AirPlay 2 с iPhone: обнаружение, музыка и аппаратная громкость Android, обратная синхронизация громкости с пульта.
- Команды Play/Pause через защищённый локальный интерфейс AirPlay 2.
- Необязательный мост «Алиса, пауза»: использует событие штатного SDK; свой распознаватель речи не устанавливается.
- Штатная остановка дочерних процессов, отдельные файлы установки и обратимый откат.
- Ограниченные логи и защита от ошибочного использования старых PID после перезагрузки.

На исходной станции работа звука и команд подтверждена владельцем (**LOCAL-CONFIRMED**, 10 ноября 2026). Длительность последней проверки и полный перечень команд не указаны. Mac, Next/Previous, длительная работа новой упаковки и её установка/удаление на Android — **UNKNOWN**, ожидают проверки. Код команд Next/Previous присутствует, но эти функции не заявляются проверенными. Голосовой мост может реагировать на штатную паузу при другом обращении к Алисе; точность такого различения отдельно не подтверждена. Работа без облака также не доказана.

## Быстрая установка

Скачайте установочный архив **и SHA256SUMS** из GitHub Release, проверьте SHA-256 и распакуйте архив. Нужны Python 3.12+ и Android Platform Tools (`adb`) на компьютере. Подключите принадлежащую вам станцию через уже настроенный ADB, затем из распакованной папки выполните:

```sh
python3 install.py --model YNDX-00052 --root rootd --hybrid-root-version 1.2.4 --voice on
```

Это вариант для **уже установленного Hybrid Root 1.2.4**. Установщик проверит совместимость, покажет изменения и попросит ввести `YES`. При нескольких ADB-устройствах добавьте `--serial АДРЕС_ИЛИ_СЕРИЙНЫЙ_НОМЕР` локально; не публикуйте этот идентификатор в отчётах.

После успешной установки выберите **YA Station Custom** в меню AirPlay. Полный порядок с проверками и другими способами root приведён в [INSTALL.md](INSTALL.md).

## После перезагрузки

Автозапуск предусмотрен **только через уже существующий root hook `/data/adb/service.d`**, отдельно с `--autostart required`. Если hook отсутствует, установка с этим параметром откажет. Установщик не создаёт новый механизм root и не пишет в системные разделы.

На исходной станции с Hybrid Root такой hook не обнаружен. Для неё автоматический запуск пока **не подтверждён**: после перезагрузки используйте команду `start` из INSTALL.md. Это открытый блокер стабильного релиза, а не обещание работающего автозапуска на Hybrid Root.
